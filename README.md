# twl アプリ

ブラウザからインストールして、専用の窓とアイコンで使えるアプリです(PWA)。
インストールしたあとは、インターネットなしでも開けます。

## はじめかた(Mac)

1. このフォルダ(`todo-app`)を、好きな場所に置きます。
2. ターミナルで、このフォルダに移動して、次を実行します。

   ```
   python3 -m http.server 8123
   ```

3. Chrome で `http://localhost:8123` を開きます。
4. アドレスバーの右にある「インストール」のアイコン(または、メニューの「キャッシュ、保存、共有」→「ページをアプリとしてインストール」)を押します。

インストールしたあとは、Dock / Launchpad のアイコンから開けます。ターミナルは閉じて大丈夫です。

## 注意

- **データ**は、ブラウザの中(`localhost:8123` の分)に保存されます。ポート番号(8123)を変えると、別の保存場所になって、タスクが見えなくなります。
- `todo.html` を直接開いて使っていた分のタスクは、引き継がれません。
- アプリを更新するときは、`sw.js` の `VERSION`(例: `todo-v4` → `todo-v5`)を変えてください。
- `http://localhost` 以外で使うときは、https で公開する必要があります(GitHub Pages、Netlify など)。
